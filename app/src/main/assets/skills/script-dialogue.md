# script-dialogue.md · 剧本与对白

## 格式

```markdown
## 场景 1 · 内景 · 夜 · 咖啡馆

（林夏推门，风带进雨声）

林夏：还是那个位置？
店主：（擦杯）你每次都问。

（林夏坐下，把湿透的信封放在桌上）
```

## 对白规则

1. 一人一句，超过 3 行独白就拆动作。
2. 潜台词优先：角色不说出真实意图。
3. 每 5 轮对话推进一次信息或关系变化。
4. 方言/口癖最多两个角色使用，避免全员一个腔。

## 场景要素

- 目标：这场戏谁想干什么
- 阻碍：谁/什么挡着
- 转折：结尾状态必须和开头不同

## 验收

- [ ] 遮住角色名也能分辨谁在说话
- [ ] 每场戏都有状态变化
- [ ] 舞台提示可执行（演员看得懂）
