# accessibility-i18n.md · 无障碍与多语言

## 无障碍

- 所有图标有 `contentDescription`，装饰性图标显式置空。
- 触控热区 ≥ 44dp；文字缩放 200% 不截断。
- 颜色对比 ≥ 4.5:1（正文），色盲友好：不只靠颜色区分状态。
- 支持系统字体缩放：布局用 `sp`，不要写死 px。

## 多语言

- 文案抽到资源文件，不在代码里拼中文。
- 占位符用命名参数：`{count}` 而不是 `%s`。
- 日期/数字用 locale 格式化。
- 布局留 30% 余量（德语/俄语更长）。

## 验收

- [ ] 系统字体调到最大，界面可用
- [ ] TalkBack 能读完关键操作
- [ ] 切换语言不崩，无硬编码中文
