# data-model.md · 数据建模

## 原则

1. **表驱动**：数值、文案、配置放数据文件，不写死在代码。
2. **有版本**：任何持久化结构第一字段是 `version`，读时做迁移。
3. **可空显式**：缺省值写清楚，不用 null 表示「0」。
4. **单一真相**：同一数据只有一处权威来源，其余是派生。

## 存档模板

```json
{
  "version": 2,
  "slot": "auto",
  "player": { "hp": 100, "x": 12.5, "y": 3.0 },
  "flags": { "tutorialDone": true }
}
```

## 迁移

- v1 → v2：新增字段给默认值；删除字段先保留两版再清。
- 迁移函数纯函数化，可单测。

## 验收

- [ ] 旧存档能读（至少上一版）
- [ ] 缺字段不崩
- [ ] 存档写入原子（tmp + rename）
