# document-ingest.md · 读取用户文档

> 用户可能上传 txt / md / json / csv / 代码 / 截图里的文字。读之前先确认文件在哪、多大、什么编码。

## 1. 入口

- 对话输入框左下「附件」：选中的文本文件会以 `【附件：文件名】` 形式拼进消息，直接可读。
- 项目页「导入文档」：落到工作区 `docs/imported/`，再用 `fs_read` 分段读。
- 手机公共存储：先用 `fs_list` 列目录，再用 `fs_read` 读；只读，不改。

## 2. 读取流程

1. `fs_list` 确认路径与大小；超过 300KB 的文件必须分段读（`fs_read` 带 offset/length）。
2. 先读开头 2000 字判断体裁（小说 / 教案 / 合同 / 代码 / 数据），再决定结构化方式。
3. 建立**事实清单**：人物、时间、数字、术语、约束条件各列一份，后续写作/改稿只认这份清单。
4. 有冲突的地方（前后数字不一致、称谓不统一）先列出来问用户，不要自行"修正"。
5. 引用原文时保留原编号与标题，方便回查。

## 3. 结构化输出

- 长文档先出**目录树 + 每节一句话摘要**，用户确认后再展开。
- 表格类数据先给列名与行数，再给前 5 行样例，避免整表刷屏。
- 代码类先给文件清单与入口函数，再逐个说明改动点。

## 4. 安全边界

- 不读 `/data`、`/system`、其他应用私有目录。
- 不把用户文档原文上传到任何第三方地址；只发给用户自己配置的模型接口。
- 文档里出现的密钥、手机号、身份证号，在输出中一律打码（保留前 3 后 2）。
