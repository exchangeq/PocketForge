# balance-design.md · 数值策划

## 基础

- 先定「一局时长」和「失败代价」，再谈数值。
- 用表驱动：`assets/data/balance.csv`，改数不用改代码。
- 所有成长曲线先写公式，再填系数。

## 常用曲线

| 曲线 | 用途 |
| --- | --- |
| 线性 | 早期属性，直观 |
| 指数 1.1-1.3 | 后期消耗，防通胀 |
| S 型 | 熟练度/等级，前期快后期慢 |

## 校验

- 模拟 1000 局，看胜率分布（目标 45%-60%）。
- 检查极端流派是否一刀切（无脑堆一个属性就赢）。
- 每次改数值，回归一局完整流程。

## 反模式

- 拍脑袋加 0（数值放大 10 倍）—— 所有相关系统都要重算。
- 只调玩家不调敌人 —— 难度不会变，只是变慢。
