# debugging.md · 排障手册

## 顺序（不要跳）

1. **复现**：固定输入、固定环境，确认 100% 能重现。
2. **缩小**：二分注释/二分数据，找到最小触发集。
3. **看日志**：时间戳、异常栈、前后状态，一次只看一个变量。
4. **假设 → 验证**：一次只改一个假设，改完立刻跑。
5. **修因不修果**：不要在报错行加 try/catch 掩盖。

## 常见坑

| 现象 | 常见根因 |
| --- | --- |
| 点不动 | 布局高度 0（weight 用错）、透明遮罩拦截 |
| 永远加载中 | 异常路径没清状态、请求无超时 |
| 写完读不到 | 写到私有目录，读的是公共目录 |
| 乱码 | 未指定 UTF-8 |

## 报告格式

```
现象：…
复现：1) … 2) …
根因：…
修法：…（改了哪些文件）
验证：…
```
