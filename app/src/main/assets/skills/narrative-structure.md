# narrative-structure.md · 叙事结构

## 三幕（长篇通用）

| 幕 | 占比 | 任务 |
| --- | --- | --- |
| 第一幕 | 25% | 建立常态 → 打破常态 → 主角被迫行动 |
| 第二幕 | 50% | 升级对抗 → 中点反转 → 最低谷 |
| 第三幕 | 25% | 决战 → 代价 → 新常态 |

## 网文节奏（更密）

- 每 3 章一个小高潮，每 10 章一个大转折。
- 章末钩子：悬念 / 反转 / 危机 / 新信息，四选一，不许空手结尾。
- 前三章必须交代：主角要什么、谁挡着、失败代价是什么。

## 结构检查

- [ ] 每一章都有「目标 - 阻碍 - 结果」三要素
- [ ] 主角每次胜利都付出代价
- [ ] 反派有可理解动机（不是纯恶）
