# system-dev.md · 系统层开发

> 配置、日志、存储、权限、生命周期。系统层写烂了，业务层再漂亮也白搭。

## 硬规则

1. **配置只读加载 + 显式保存**：启动读一次进内存，改完手动 save，不搞到处 set 全局。
2. **密钥不进配置文件**：密钥走 Keystore（本 App 是 AES-256-GCM + Keystore 包裹）。
3. **写文件必须原子**：先写 `.tmp` 再 rename，防断电写半截。
4. **日志按天切 + 上限**：单文件 2MB 就截断，禁止无界增长。
5. **权限失败要可降级**：拿不到全盘权限就退到应用私有目录，并明确告知用户。

## Android 权限清单

| 能力 | 权限 | 拿不到时的降级 |
| --- | --- | --- |
| 读写根目录 | MANAGE_EXTERNAL_STORAGE | 仅私有目录 |
| 旧版本存储 | READ/WRITE_EXTERNAL_STORAGE | 同上 |
| 后台执行 | FOREGROUND_SERVICE | 前台才跑 |

## 生命周期

- Activity 重建不能丢状态：进度存 ViewModel/SessionStore，不存静态变量。
- 长任务放协程 + 可取消；取消时释放连接与文件句柄。

## 验收

- [ ] 杀进程再开，配置与进度不丢
- [ ] 拔电源模拟：存档不损坏
- [ ] 权限拒绝时有提示，不是崩溃
