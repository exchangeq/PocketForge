# worldbuilding.md · 世界观

## 三条硬规则

1. **一句话规则**：世界为什么和现实不同，一句话说清。
2. **代价**：任何超能力/技术都有成本，否则冲突消失。
3. **边界**：明确「不做什么」，防止后期无限膨胀。

## 文档结构

```markdown
# 世界观
## 一句话
## 硬规则（3-5 条，锁死）
## 地理（主舞台 + 边缘）
## 势力（谁控制什么资源）
## 日常（普通人怎么活）
## 禁忌（不写的东西）
```

## 自检

- [ ] 规则能推出剧情冲突，而不是靠巧合
- [ ] 主角的困境在这个世界成立
- [ ] 没有「因为作者需要」的设定
