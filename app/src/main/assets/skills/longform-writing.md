# longform-writing.md · 长篇连载

## 开工顺序

1. `world.md`（硬规则 + 地理）→ 锁定
2. `cast/cast.md`（人物表 + 关系）
3. `outline.md`（分卷 → 每卷 5-8 章梗概）
4. `continuity.md`（伏笔账本，边写边登记）
5. `style-guide.md` → 锁定

## 单章流程

```
读大纲本章目标 → 读 continuity 未回收伏笔 → 写初稿 → 自检 → 改稿 → 登记伏笔 → 更新进度
```

## 单章结构（3000-4000 字）

- 开场 300 字：承接上章钩子，立即给冲突。
- 中段 2500 字：两次信息增量，一次小反转。
- 收尾 300 字：新钩子 + 留白。

## 硬规则

- 锁定文件（world/style-guide）**不许改**，要改先解锁并说明原因。
- 人物口吻参照 `character-card.md`，同一角色不漂移。
- 每章写完更新 `continuity.md`，未登记的伏笔算 bug。

## 验收

- [ ] 章节编号连续
- [ ] 本章至少推进一条主线或支线
- [ ] 无「上一章已经说过」的重复信息
