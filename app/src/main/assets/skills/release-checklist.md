# release-checklist.md · 发布检查

## 发版前

- [ ] 版本号 +1（versionCode 单调）
- [ ] 变更日志写清「修了什么、加了什么」
- [ ] 签名指纹与上一版一致
- [ ] 冷启动无崩溃（logcat 干净）
- [ ] 关键路径手测：配置 → 对话 → 写文件 → 重开
- [ ] 体积变化有解释

## 资产

- [ ] APK 命名 `产品-版本-类型.apk`
- [ ] release 与 debug 都传，标注体积
- [ ] 校验 sha256，写在 release 页

## 发布后

- [ ] 安装链接可下载
- [ ] 旧版可直接覆盖升级（不丢配置）
- [ ] 记录坑点，进 CHANGELOG
