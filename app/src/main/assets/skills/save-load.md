# save-load.md · 存档系统

## 结构

```json
{
  "version": 2,
  "createdAt": "2026-11-19T21:00:00+08:00",
  "playtime": 3720,
  "player": { "hp": 80, "x": 12.5 },
  "flags": { "chapter": 3 },
  "inventory": [{ "id": "potion", "n": 2 }]
}
```

## 硬规则

1. 写入原子：tmp + rename。
2. 版本号必填，读档先迁移再反序列化。
3. 缺字段给默认值，不崩。
4. 自动存档单独槽位，不覆盖手动档。
5. 存档前打快照，损坏可回滚一档。

## 验收

- [ ] 强杀进程后存档可读
- [ ] 旧版本存档能迁移
- [ ] 存档损坏时提示并可回滚
