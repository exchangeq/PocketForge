# level-design.md · 关卡设计

## 单个关卡三问

1. 教会玩家什么？（新机制/新组合）
2. 难点在哪？（操作/资源/信息）
3. 失败后学到什么？（不能是纯运气）

## 结构

```
引入（安全区教学）→ 发展（组合压力）→ 高潮（一个硬点）→ 收尾（奖励+钩子）
```

## 难度曲线

- 同章节内：易 → 中 → 难 → 喘息关。
- 新机制首次出现必须无惩罚试错。
- 检查点放在高潮前，不要放高潮后。

## 验收

- [ ] 首次通关率 ≥ 60%（测试组）
- [ ] 失败原因可归因（不是「不知道怎么就死了」）
- [ ] 每关有唯一标识的视觉记忆点
