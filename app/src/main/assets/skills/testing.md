# testing.md · 测试与自检

## 分层

| 层 | 做什么 | 放哪 |
| --- | --- | --- |
| 单元 | 纯函数/解析/状态机 | `tests/unit` |
| 集成 | 文件读写、存档往返 | `tests/integration` |
| 冒烟 | 启动 → 核心流程 → 退出 | `tests/smoke` |

## 必测清单（每个项目通用）

1. 空输入 / 超长输入 / 非法字符
2. 文件不存在 / 目录不存在 / 只读目录
3. 中途取消任务，状态是否干净
4. 重复执行是否幂等

## 写法

- 一个测试只断言一件事，名字写清「输入 → 期望」。
- 用临时目录，不污染工作区。
- 测试失败先复现，别先改断言。

## 输出格式

```
通过 12 / 失败 2
- FAIL：parseTable 空表头 → 期望空数组，实际抛异常
```
