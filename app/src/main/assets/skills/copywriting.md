# copywriting.md · 文案

## 结构

```
钩子（1 句，痛点或反差）→ 价值（2-3 条具体收益）→ 证据（数字/案例）→ 行动（一句话）
```

## 规则

- 标题 ≤ 20 字，前 8 字放关键词。
- 一条文案只讲一个卖点。
- 数字具体：不说「大幅提升」，说「从 8 分钟到 90 秒」。
- 禁用绝对化用语（最、第一、100%）。

## 平台差异

| 平台 | 长度 | 语气 |
| --- | --- | --- |
| 应用商店 | 80 字内 | 功能直给 |
| 公众号 | 300-800 字 | 故事 + 干货 |
| 信息流 | 30 字内 | 冲突前置 |

## 验收

- [ ] 去掉形容词仍成立
- [ ] 用户能复述卖点
