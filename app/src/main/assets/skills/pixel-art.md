# pixel-art.md · 像素风

## 硬规则

1. **整数缩放**：只按 2x/3x/4x 放大，禁止插值（nearest 采样）。
2. **调色板控制**：一个角色 ≤ 8 色，全场景 ≤ 32 色。
3. **基准尺寸**：角色 16/24/32px，地图瓦片 16 或 32。
4. **描边**：用深色统一描边，不逐像素乱点。
5. **抖动**：只用规则 Bayer 抖动做渐变，别手抹。

## 命名与目录

```
assets/images/char/<角色>_<动作>_<帧号>.png
assets/images/tile/<地形>.png
```

## 验收

- [ ] 100% 缩放查看无半像素
- [ ] 角色在深色/浅色背景都可辨识
- [ ] 动画帧数对齐（同一动作帧数一致）
