# ui-design.md · 界面设计

## 四条底线

1. **一个主色**，最多两个辅助色；背景比卡片浅，卡片白底细描边。
2. **字号只三档**：大标题 22-28，正文 15-17，辅助 11-13；行高 = 字号 × 1.4。
3. **间距用 4 的倍数**：4/8/12/16/24，不要 7dp、13dp 这种手抖值。
4. **圆角成套**：8（小）/10-12（卡）/16-20（气泡）/圆形（按钮）。

## 结构

- 页头：标志 + 标题 + 状态；不要塞超过 2 个操作。
- 内容区：卡片分组，组间 16，组内 8。
- 底栏：3-5 项，图标 + 文字，选中态用主色。

## 反例

- 每个卡片不同圆角、不同阴影 —— 廉价感来源。
- 用红色表示「可发送」—— 语义错误，红=危险。
- 重要按钮放在滚动区外却不可见 —— 一定点不到。

## 验收

- [ ] 深色模式下对比度仍可读
- [ ] 拇指热区 ≥ 44dp
- [ ] 键盘弹出不遮挡输入框
