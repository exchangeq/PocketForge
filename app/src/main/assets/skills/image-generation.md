# image-generation.md · 生图规范（image_generate）

> 默认走 **Pollinations 免费通道**（`https://image.pollinations.ai`，不用 Key、不耗额度），
> 模型 `flux`（画质最好）/ `turbo`（更快）；需要自有模型时在设置里切「OpenAI 兼容」。
> 生成即落盘 `assets/images/`，同时写 `meta.jsonl`（提示词、尺寸、通道），图库页可直接复用。

## 1. 提示词结构（缺一项都会画偏）

```
主体（谁/什么，数量要写死）
+ 动作/状态（在做什么）
+ 场景（在哪里、季节/天气/年代）
+ 镜头（特写 / 半身 / 全身 / 俯视 / 平视 / 广角）
+ 光线（顺光 / 逆光 / 窗边自然光 / 霓虹 / 阴天）
+ 风格（写实摄影 / 胶片 / 像素 / 水彩 / 扁平插画 / 3D 渲染）
+ 色彩（主色 + 点缀色，低饱和/高对比要明说）
+ 构图（居中 / 三分 / 留白位置，给文字留白要写清）
+ 画幅与用途（海报竖版 3:4、封面 16:9、头像 1:1）
```

负向要求直接写进句子："不要文字、不要水印、不要多余手指、不要畸形肢体"。

## 2. 尺寸选择

| 用途 | size |
| --- | --- |
| 头像 / 图标 / 商品方图 | `1024x1024` |
| 竖版海报 / 手机封面 | `1024x1536` |
| 横版头图 / 视频封面 | `1536x1024` |

工具参数：`{"prompt": "...", "size": "1024x1536", "model": ""}`，model 留空用设置里的。
免费通道下 model 只建议 `flux` / `turbo`，别填 `gpt-image-1`（会被自动纠正成 flux）。

## 3. 数量门禁（硬规则）

- 用户明确要求"图里有 N 个 X"时，**先读图核对总数与分类数量**，全部正确才给用户看；核不对就重画，不能糊弄。
- 没有数量要求的图，生成成功直接展示，不要再问"要不要看看"。
- 多图按生成顺序逐张展示，别只给第一张。

## 4. 结果处理

- 保存路径：`assets/images/img-<时间戳>-<序号>.png`（ImageClient 自动命名）。
- 对话里会自动贴出图片；同时在 `PROGRESS.md` 里留一行"生图 · 文件名 · 用途"。
- 生成失败（401/429/额度）把原始错误说清楚，并给替代方案（换模型、改尺寸、稍后再试），不要只说"失败了"。

## 5. 项目里的用法

- 游戏：角色立绘、场景概念图、UI 图标、道具图标 → 放进 `assets/images/` 并在 `design/gdd.md` 记用途。
- 写作：封面、章节插图、人物卡头像 → 放进 `export/images/`。
- 应用：启动图、空状态插画、应用图标 → 放进 `src/main/res/drawable/` 时说明尺寸。

## 6. 禁止

- 不生成真实公众人物的伪造肖像、不生成违法/暴力/色情内容。
- 不把用户上传的私人照片当公开素材二次分发。
- 不伪造"已生成"：工具没返回成功就不能在回答里说画好了。
