# image-pipeline.md · 图片管线

## 原则

1. **按用途定尺寸**：UI 图标 ≤ 96px，场景图按屏宽 1.5 倍，不要直接放 4K 原图。
2. **格式**：带透明用 PNG/WebP，照片用 WebP（质量 80）。
3. **图集**：小图合并，减少 draw call；图集尺寸 2048 上限。
4. **命名**：`<场景>_<对象>_<状态>.png`，全小写下划线。

## 处理顺序

```
原图 → 裁剪 → 缩放 → 压缩 → 命名 → 放 assets/images
```

## 验收

- [ ] 单图 ≤ 500KB，图集 ≤ 4MB
- [ ] 透明边缘无白边
- [ ] 不同 dpi 下不糊
