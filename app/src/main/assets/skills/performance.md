# performance.md · 性能

## 先测量再优化

- 打点：开始/结束时间戳，记录 P50/P95，不看单次。
- 三项预算：启动 ≤ 1.5s、单帧 ≤ 16ms、单次 IO ≤ 50ms。

## 高频问题

1. **主线程 IO**：读文件、解析 JSON 必须离主线。
2. **重复分配**：循环里 new、字符串拼接。
3. **大图未压缩**：先缩到显示尺寸再解码。
4. **无界缓存**：LRU 上限要写死。
5. **全量刷新**：列表用 diff，不要整表重建。

## 手段

- 对象池、预分配、懒加载、分页读取（大文件按行流式处理）。
- 批量写：多次小写合并成一次 `append`。

## 验收

- [ ] 有前后对比数据（不是「感觉快了」）
- [ ] 极端输入（1 万行/100MB）不崩
