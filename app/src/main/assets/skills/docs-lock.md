# docs-lock.md · 文档锁定规程

> 用途：把定稿的东西钉住，防止 AI「顺手优化」把设定改烂。

## 三种锁

| 工具调用 | 效果 | 适用 |
| --- | --- | --- |
| `doc_lock(path)` | 整篇保护（soft），覆盖需 override=true | 文风、世界观 |
| `doc_lock(path, sections=[...])` | 只锁指定章节，其余可续写 | 小说正文已定稿章 |
| `doc_lock(path, hard=true)` | 硬锁，任何写入都拒绝 | 合同、基线数据 |

## 标准流程

1. 内容写完 → 读回自检 → `doc_lock`，note 写清「为什么锁」。
2. 需要修改 → `doc_unlock` → 改 → 再 `doc_lock`（别锁完忘了）。
3. 新增章节 → 只锁老章节，新章节保持可写。

## 禁止

- 不锁未完成草稿（会卡住自己）。
- 不用硬锁锁自己还要频繁改的模板。
- 不绕过锁（除外用户明确要求，且回复里说明解锁动作）。

## 验收

- [ ] `doc_locks` 能看到清单与范围
- [ ] 改动锁定章节被拒绝，提示可读
