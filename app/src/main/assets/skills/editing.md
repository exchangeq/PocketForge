# editing.md · 改稿与去 AI 味

## 去 AI 味 Checklist

1. 删掉「不禁」「仿佛」「这一切」「命运的齿轮」这类套话。
2. 形容词换动作：不写「他很愤怒」，写「他把杯子磕在桌上」。
3. 排比句砍到最多两段，不要三段堆。
4. 每段第一句不要都是「他……」，换主语或换视角。
5. 删掉总结陈词（「从此，他明白了……」）。
6. 对话去掉解释性旁白，让台词自己说话。

## 改稿顺序

```
结构（有没有推进）→ 节奏（有没有拖）→ 语言（有没有套话）→ 错字
```

## 保留原则

- 作者的怪癖用词可以留，AI 的工整模板必须删。
- 改完对比朗读一遍，拗口就回退。

## 验收

- [ ] 抽三段给旁人读，说不出「像 AI 写的」
- [ ] 每千字至少一个具体细节（气味/声音/触感）
