# personas · 人设包（不内置，按需下载）

App 的「对话 → 设定 → 仓库人设包 → 加载列表 → 下载」会读这里的 `index.json`。  
仓库只存放文本，**不会打进 APK**，谁需要谁下。

## 自己加一个包

1. 写一个 `.md`，开头可以放 `// 作者：xxx` 这类注释行，App 注入时会自动剔除；
2. 在 `index.json` 的 `packs` 里加一条：
   ```json
   { "id": "my-char", "name": "角色名 · 一句话定位", "desc": "适合什么场景", "files": ["my-char.md"] }
   ```
3. `files` 可以给多个文件，App 会按顺序拼接后注入。

## 注意

- 人设**写入即锁定**，App 内不可修改、不可删除；想换只能新建对话页。
- 单包建议 ≤ 1.2 万字，太长会挤占上下文，回答质量反而下降。
